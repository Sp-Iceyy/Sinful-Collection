# Sinful Collection

Sinful Collection is a private desktop application for organizing local images and videos.

## What It Does

- Creates separate profiles with separate media libraries.
- Imports individual files, batches of files, or an entire folder.
- Lets you edit titles, artists, tags, folders, and NSFW status.
- Organizes media by Favorites, Folders, Artists, and Tags.
- Supports video playback, seeking, mute, fullscreen, and ten-second skipping.
- Stores imported media in user-selected `Images` and `Videos` folders.
- Opens stored media in File Explorer and supports changing the storage location.

## Run the App

Grab the setup from releases and run, a new program named "Sinful Collection" should show in your start menu.

## First Launch

After opening the app, create your profile; this will be your collection, collections do not transfer between profiles.
I recommend using this feature to sort further. i.e. a gposer in ffxiv might use one profile for their gposes, another for venue photos, another for x etc etc.

After making your profile, press the help button near the top (not in the file bar) and press "change media location", this will open file explorer where you can choose to store all the media you add to your collection. (note: adding to collection will make a copy of the media you add, preserving the file in it's original location)

## Library

This is the meat and potatoes of the application; everything you add to your collection will appear here.

## Adding Media

Pressing either the "Add Media" button will allow you to pick your images or videos from your drive, and add it to your collection. Also allows drag and drop onto the program.
There are multiple boxes available, that being:
-title (what you name it)
-artist (who made it)
-tags (one word descriptors of what it is, separated by commas)
-description (further detailed description of what it is)
-folder (what folder it gets stored in for the "Folders" tab)

####IMPORTANT:
regarding drag and drop functionality; it currently does not work with multiple files at a time, only single files. Will be fixed next update.
